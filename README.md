# ChatGPT Tower Defense — NEXUS

Um Tower Defense futurista em português, criado para funcionar no navegador de computadores e celulares.

## Jogar

A versão publicada está em: https://nexus-defense-cleiton.chat2026-utopia002.chatgpt.site

Escolha uma torre, toque em uma plataforma numerada e inicie a onda. Sobreviva às 15 ondas e proteja o núcleo dos três chefes.

## Recursos

- Três torres com funções distintas: Pulso, Canhão e Cryo
- Evolução até o nível 3 e venda de torres
- Quinze ondas, três chefes e inimigos com atributos variados
- Velocidade dupla, pausa, efeitos sonoros opcionais e recorde local
- Interface responsiva com controles próprios para celular e modo paisagem
- Sem dependências ou instalação: HTML, CSS e JavaScript

## Executar localmente

Sirva a pasta `dist` com qualquer servidor HTTP estático e abra `index.html`.

## Estrutura

- `dist/index.html`: interface do jogo
- `dist/style.css`: direção visual e layouts responsivos
- `dist/game.js`: motor, combate, progressão e renderização em Canvas
